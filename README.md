## Local Development

```bash
git clone https://github.com/Kishordiu/proto-1d-omar-babu.git
cd <project-directory>
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

Run the test suite when available:

```bash
npm run test
```
